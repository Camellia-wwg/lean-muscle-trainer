# 薄肌训练

一个单文件的徒手训练与饮食执行工具。离线可用，数据只保存在本地浏览器，不上传任何服务器。

## 功能

- **自动判断今天练什么**：按日期推算今天是 A 日、B 日还是休息日，休息日显示下一次训练是哪天练哪套
- **组间休息倒计时**：每完成一组自动开始计时，归零时响铃并震动，可延长或跳过
- **逐组打勾**：进度条实时更新，动作全部完成自动置灰
- **自动进阶判断**：记录每组次数并显示上次成绩，达到进阶条件时提示降低支撑高度进入下一档
- **体重趋势**：原始值加 7 天移动平均曲线，按周变化速度自动给出热量调整建议
- **训练频率热力图**：最近 8 周的完成情况一目了然
- **饮食模块**：每日餐次、采购清单可勾选、备餐步骤、抗腻轮换方案
- **数据备份**：一键导出为 JSON 文件，支持导入还原，另有剪贴板兜底
- **打乱期模式**：设定作息被打乱的日期区间，App 自动切换为低强度维持方案
- **深色模式**，移动端优先的响应式布局

## 技术

纯静态单文件，零依赖零构建。原生 JavaScript，图表为手写 SVG，数据持久化使用 localStorage，音频提示使用 Web Audio API。

## 使用

直接打开 `index.html`。首次运行会引导填写身高体重、训练日、动作难度档位等配置，全部保存在本地，随时可在设置里修改。
